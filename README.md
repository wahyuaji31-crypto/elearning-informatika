# E-Learning Informatika

Aplikasi web pembelajaran E-Learning Informatika yang dilengkapi dengan fitur materi, tugas, dan integrasi pembelajaran interaktif.

## 📁 Struktur Berkas

- `index.html` - Halaman utama aplikasi E-Learning
- `elearning informatika.html` - Halaman materi dan modul pembelajaran

## 🚀 Cara Menjalankan

Buka berkas `index.html` langsung di peramban web (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
